علامت `>` برای Quote است، و `[!type]` نوع کال‌اوت را مشخص می‌کند.
Callout در Obsidian یک **جعبه‌ی برجسته**‌ است که برای هایلایت‌کردن بخش‌های مهم متن استفاده می‌شود؛ مثل نکته، هشدار، مثال، یا خلاصه.  
از نسخه 0.14 به بعد به‌صورت پیش‌فرض پشتیبانی می‌شود.

---------------------------------------

## Callout دقیقاً چطور ساخته می‌شود؟
با این ساختار:

```
> [!type] عنوان اختیاری
> متن داخل کال‌اوت
```

علامت `>` برای Quote است، و `[!type]` نوع کال‌اوت را مشخص می‌کند.

---------------------------------------

## چه مدل‌هایی وجود دارد؟ (لیست کامل انواع پیش‌فرض)
انبوه نیستند، ولی کاربردی‌اند. معروف‌ترین‌ها:

### 1) note  
```
> [!note] یادداشت
> این یک یادداشت ساده است.
```

### 2) info  
```
> [!info] اطلاعات
> توضیحات یا اطلاعات بیشتر.
```

### 3) tip / hint  
```
> [!tip] نکته
> چیزی که به کاربر کمک می‌کند.
```

### 4) warning / caution  
```
> [!warning] هشدار
> مراقب این بخش باش.
```

### 5) danger / error  
```
> [!danger] خطر
> این کار می‌تواند مشکل ایجاد کند.
```

### 6) success / check / done  
```
> [!success] موفق
> کار با موفقیت انجام شد.
```

### 7) example  
```
> [!example] مثال
> این یک نمونه کاربرد است.
```

### 8) quote  
```
> [!quote] نقل‌قول
> جمله‌ی نقل‌شده.
```

### 9) abstract / summary / tldr  
```
> [!summary] خلاصه
> نتیجه‌گیری به‌صورت کوتاه.
```

### 10) bug  
```
> [!bug] باگ
> رفتار غیرمنتظرهٔ نرم‌افزار.
```

### 11) faq  
```
> [!faq] سوالات متداول
> پاسخ یک سوال تکراری.
```

---------------------------------------

## نکته‌های مهم و کمتر‌معروف
### ۱) کال‌اوت‌ها می‌توانند جمع‌شونده باشند  
فقط کافی است بعد از type یک `-` بگذاری:

```
> [!note]- عنوان
> این متن به‌صورت تاشونده است.
```

### ۲) می‌توانی عنوان را حذف کنی  
```
> [!info]
> فقط متن داخل جعبه.
```

### ۳) داخل کال‌اوت می‌توانی Markdown کامل داشته باشی  
- لیست  
- کد  
- تصویر  
- لینک  
- کال‌اوت داخل کال‌اوت

---------------------------------------
